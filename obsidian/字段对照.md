# 字段对照（Obsidian ↔ App）

约定：frontmatter / `##` 标题 = **可导入内容**；标注「App 专属」的字段由应用维护，同步时不覆盖。

## 知识框架 → KnowledgeNode

| MD | App |
|----|-----|
| 文件名 stem | `tree_key` |
| `##` / `###` / 列表 | `title` + `path` + `depth` |
| 标题下段落 | `content` |
| — | `my_note` / `is_starred` / SRS（App 专属） |

## 行测错题 → ManualWrong

| MD | App |
|----|-----|
| `id` | `id` |
| `subject` / `question_type` / `wrong_reason` / `source` | 同名字段 |
| `knowledge_tree_key` / `knowledge_path` | `knowledge_tree_key` / `knowledge_path` |
| `## 题干` … `## 备注` | `stem` / `options` / `my_answer` / `correct_answer` / `analysis` / `note` |
| — | `review_*` / `mastered`（App 专属） |

## 时政文章 → Article

| MD | App |
|----|-----|
| frontmatter 元数据 | `title` / `source` / `tags` / `importance` … |
| `#` / `##` / `###` / `>` | `sections` JSON（章/节/段） |

## 人民日报文章 → RmrbArticle

| MD | App |
|----|-----|
| frontmatter | `title` / `source` / `publish_date` / `summary` / `tags` … |
| `tags` | 主题标签，如政绩观、社会治理、乡村振兴、县域经济 |
| 正文 | `content` |

## 开采本 → ShenlunMineLog

| MD | App |
|----|-----|
| `mine_date` / `article_*` | 同名 |
| `## 原文摘录` | `source_excerpt` |
| `## 总骨架` + 分论点 | `argument_json`（分论点：标题→`title`，论据→`evidence`，小结→`summary`，论证方法→`method`，方法说明→`methodNote`，套用模板→`template`） |
| `## 规范词` 表 | `terms_json` |
| `## 语录` | `quotes_json` |
| `## 高频动词` 表 | `verbs_json` |
| `## 句式模板` | `templates_json` |

## 规范词 → ShenlunNormTerm

| MD | App |
|----|-----|
| `term` / `category` / `source_title` / `article_id` | 同名 |
| `## 示例句` / `## 用法备注` | `example_sentence` / `usage_note` |
| — | `familiarity` / `mastered`（App 专属） |

## 语录 → quotes 条目

| MD | App |
|----|-----|
| `## 原文` / `## 释义` / `source` | `text` / `meaning` / `source` |

## 语料本 → CorpusItem

| MD | App |
|----|-----|
| `kind` / `source_type` / `source_title` / `tags` | 同名 |
| `## 原文` … `## 运用` | `original` / `plain_note` / `rewrite` / `practice` |
| — | `status` / `used_count`（App 专属） |
