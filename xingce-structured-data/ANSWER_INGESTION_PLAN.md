# 2025 真题答案接入 · 执行计划

> 目标：把 2025 三卷（省级 135 / 市地 130 / 执法 130）的**答案、解析、细题型**接入结构化库，
> 并基于此完成第一次「真题规律」实证统计，反哺政治理论出题规范。
> 制定：2026-09-02 · 前置：用户将手动扫描**独立集中排版**的解析册 PDF

---

## 0. 本轮核心风险：题号错位

解析册集中排版意味着**答案与题干不同页**，只能靠题号对齐。而本项目有两个天然错位源：

1. **三套卷题号不同**：同一道共享题在省级是 88 题、在市地可能是 83 题（省级数量 15 题、另两卷 10 题，导致判断/资料整体后移 5 题）。
2. **2024 已发生过同类事故**：市地与执法卡在 125 题（应为 130），就是差异题槽位没对齐。

**对策**：任何答案在写入前，必须通过**题干首句锚点校验**——用题号找到题目，取其题干前 12 字与解析册该题号下引用的题干片段比对，不一致即拒绝并报告。题号是索引，题干才是身份。

## 3. 阶段 1：扫描规范（**扫描前必须确认**）

集中排版的答案册，扫描质量直接决定匹配成本：

1. **答案区与解析区分开交**，或至少保证顺序为「按模块分组、模块内按题号升序」；
2. **每题必须带题号**，且题号清晰可辨（这是唯一索引）；
3. **三套卷的答案要分别可区分**：若解析册按「省级 / 市地 / 执法」分节，扫描时保留分节标题页；若只给一套答案 + 差异说明，务必扫到那段说明；
4. dpi ≥ 150，A4 竖版，**不要斜拍、不要多页拼一张**；
5. 若解析册自带「考点/题型」标注（如「本题考查……」），一并保留——这是 `subtype` 的最佳来源。

> 建议先扫 2–3 页发我试跑，确认能稳定解析出「题号 + 答案 + 解析」三件套，再批量扫全册。这样能在损失最少时间前发现格式问题。

## 4. 答案落库格式

采用**中间文件 + 脚本合并**，不手改 `papers/`，保证可重跑：

```
2025/xingce/_extract/
├── answers_shengji.json       # [{number, answer, explanation, subtype, anchor_stem}]
├── answers_shidi.json
└── answers_xzzf.json
```

合并进 `papers/*.json` 的字段：

| 字段 | 取值规范 |
|---|---|
| `answer` | 单选 `"A"`；多选 `"ABD"`（字母升序无分隔）；判断 `"正确"` / `"错误"` |
| `explanation` | 解析全文，保留「本题考查……」原句 |
| `subtype` | 细题型，如 `削弱`、`加强`、`翻译推理`、`定义判断`、`增长率计算`；无法判定时留空并在报告登记 |
| `answer_source` | `"answer_book_2026-09"`，标记答案出处便于回溯 |

合并脚本 `scripts/merge_answers.py` 职责：锚点校验 → 写入 → 输出覆盖率与异常清单。

**校验规则**（脚本强制）：
- `answer` 的字母必须落在该题 `options` 实际存在的键内；
- 判断题答案必须 ∈ {正确, 错误}；
- 多选正确项 ≥ 2；
- 锚点不匹配 → 拒绝写入，进 `pending_review` 清单人工复核。

## 5. 阶段 3：真题规律实证统计

产出 `docs/research/2025-xingce-patterns.md`，统计维度：

**结构层**
- 各模块题量与分值分布（若解析册含分值）
- 政治理论 20 题的**考点类型频次**（会议/讲话/政策/法规/重要论述…）
- 判断推理四子类（图形/定义/类比/逻辑）题量配比

**答案层（此前完全无法统计）**
- 单选正确项位置分布（A/B/C/D 是否均匀，命题有无偏好）
- 多选正确项个数分布（2 项 / 3 项 / 4 项各占比）
- 判断题「正确」与「错误」比例
- 三卷共享率：多少题三卷相同、多少仅本省、差异题集中在哪些模块

**命题手法层**
- 题干句式频次（`指出` / `强调` / `下列关于…说法正确的是` / `…不包括`）
- 选项长度规律（正确项是否系统性偏长/偏短）
- **设错手法频次**：与现有 rubric 的四类（相近表述、顺序颠倒、主体偷换、程度夸大）做映射，统计真实占比

**三卷对比层**
- 省级 vs 市地/执法的难度差异体现在哪些模块
