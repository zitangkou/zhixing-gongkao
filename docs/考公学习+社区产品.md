# 考公学习+社区产品

你的思路非常清晰——把「知行」中的公考模块剥离出来，做成一款纯粹的考公学习+社区产品，同时用“开发者备考”的养成系视频号去推广。这不仅是产品孵化，更是一个自带真实用户故事的增长飞轮。

下面我为你拆成两大部分：**新产品整体方案**（功能、布局、交互、视图）和**短视频制作体系**。方案会保留你已验证有效的功能骨架，但重新设计为更聚焦、更具传播力的产品形态。

---

## 一、新产品整体产品设计

### 1. 产品定位与名称建议

- **名称**：**“公研社”** / **“上岸笔记”** / **“仕程”**  
建议用“动词+名词”组合，如“策论”、“步岸”，好记且与考试强相关。
- **定位**：**AI驱动的公务员考试学习与备考社区**  
核心价值：用AI整理资料、规划学习、智能刷题，在社区中互相监督、分享经验。
- **用户画像**：在职备考、应届生、多次参考者，尤其青睐“用工具提效”的人群。

### 2. 功能架构（纯公考 + 社区）

所有模块围绕**学、练、测、复、社区**五环设计，砍掉英语、读书、健康等，保留并强化公考模块，新增社区。

#### 2.1 底部导航（建议4个Tab）


| Tab    | 名称  | 承载内容                  |
| ------ | --- | --------------------- |
| **学习** | 今日  | 每日规划、时政推荐、AI助手入口、复习提醒 |
| **题库** | 刷题  | 行测/申论题目练习、错题本、套卷      |
| **社区** | 社区  | 动态广场、学习小组、打卡、问答       |
| **我的** | 我的  | 学习数据、成长档案、设置、VIP      |


> 社区 Tab 放在中间，强调社交属性。

#### 2.2 学习模块（“学”）

- **首页仪表盘**  
  - 顶部：连续学习天数、今日任务完成度环形图、积分  
  - AI快捷入口：**「今日规划」** 一键生成计划 / **「帮我整理」** 拍照笔记转知识点  
  - 时政必读轮播（管理端精选）  
  - 最近复习提醒（艾宾浩斯到期卡片）  
  - **能力矩阵**：行测各模块正确率雷达图（判断推理、言语、资料分析、数量、常识）
- **时政阅读**  
  - 文章详情（保留现有分节阅读、思维导图、关联知识框架）  
  - 阅读后可直接进入该文章相关题目练习
- **知识框架**（考点树）  
  - 考公专属树：行测五模块 + 申论十大主题  
  - 节点可添加笔记、星标、掌握度，支持AI自动提炼笔记重点
- **资料分析专项**  
  - 保留公式库、题型库、秒杀技巧，增加AI即时解释（选中文字→AI解析）
- **申论专项**  
  - 人民日报时评精读（保留开采、规范词、骨架拆解）  
  - **AI批改**：用户手写申论拍照上传，OCR识别后AI从要点、逻辑、格式评分+建议  
  - 阶梯训练：造句→仿写→口述
- **学习计划**  
  - 系统根据用户目标（备考时间、每日可用时长）自动生成周计划  
  - 每日清单可拖拽调整，完成/跳过有记录  
  - 周末可启用“弹性模式”，自动降低任务量并推荐轻量复习

#### 2.3 练习模块（“练”）

- **刷题模式**（保留并优化）  
  - 今日精选（基于错题本和薄弱点推荐）  
  - 随机练习、按模块、按知识点、按文章  
  - 错题重练、收藏夹练习
- **答题交互优化**  
  - 逐题作答，即时判断对错并显示解析  
  - 每道题可收藏、添加笔记、一键提交到错题本  
  - AI解析按钮：看不懂官方解析时，让AI用更通俗的方式讲解
- **行测错题本**  
  - 手动录入（拍照上传，OCR识别题干）  
  - 自动记录错题，关联知识点，显示掌握度  
  - 错题可生成PDF打印
- **真题套卷**  
  - 历年真题 + 模拟卷，限时作答，交卷后生成成绩报告  
  - 报告包含：各模块得分、用时、正确率趋势、AI复习建议
- **AI智能组卷**  
  - 输入目标（如“资料分析弱项突破”），AI自动抽取题目组成一套小卷

#### 2.4 社区模块（核心新增）

这是新产品区别于原有工具的关键，也是未来商业化的土壤。

- **广场（信息流）**  
  - 发布图文/短视频动态  
  - 展示形式：学习打卡、笔记分享、分数进步、求助提问、经验帖  
  - 支持点赞、评论、关注
- **学习小组**  
  - 创建/加入小组（如“在职备考群”“广东选调组”）  
  - 组内打卡排行、组长督学、共享学习资料
- **每日打卡圈**  
  - 完成今日计划后可一键分享打卡图（含学习时长、正确率、坚持天数）  
  - 连续打卡获得勋章和积分
- **问答专区**  
  - 题目求助，可拍照上传，其他用户或AI回答  
  - 优质回答获赞，提升社区等级
- **成长周报（用户主页）**  
  - 类似“知行足迹”，聚合本周学习数据，可公开分享
- **积分与成就体系**  
  - 学习、打卡、回答问题、分享资料均可获得积分  
  - 积分可兑换AI批改次数、打印券等（后期变现钩子）

#### 2.5 我的模块

- 个人资料、学习档案（累计刷题数、正确率趋势、各模块掌握度）  
- 我的收藏（题目、文章、帖子）  
- 消息中心（评论、点赞、系统通知）  
- 设置（深色模式、学习提醒时间、隐私）  
- 会员中心：基础版免费，高级版含AI批改、智能组卷等（后期变现）

### 3. 交互与视觉设计原则

- **视觉风格**：沉稳、专注，采用米白/浅灰底色 + 深蓝/墨绿主色调，区别于公考培训机构的红黄扎眼风，突出“理性学习”  
- **卡片式布局**：每个功能块用轻微阴影卡片承载，圆角大，呼吸感强  
- **AI入口统一**：右下角悬浮 AI 助手按钮，可在任意页面唤起，支持语音/文字输入  
- **激励反馈**：完成学习任务有轻量动效（如撒花、打卡成功震动），利用游戏化提升粘性  
- **多端一致**：依然用 Taro + Vue3 开发 H5 + 微信小程序，优先小程序（方便分享与打卡）

### 4. 管理后台（精简为公考管理）

保留原后台中的：文章管理、知识框架、试卷题库、资料分析、人民日报、用户管理、系统设置。  
新增：社区内容审核、小组管理、积分与会员配置。

## 二、短视频制作系统方案

你没有视频经验，但“开发者备考公务员”的人设极其稀缺，这条赛道几乎没竞争对手。以下是从零开始的完整操作流程，按执行顺序排列。

### 1. 视频定位与风格

- **账号名**：直接叫“程序员考公日记” / “AI备考上岸记”，让人一眼看懂  
- **人设**：用代码和AI给自己做备考工具的开发者，记录真实学习过程，不卖课、不割韭菜  
- **风格**：**极简桌面记录风**，不露脸或只露手/背影，核心是屏幕录制+解说  
- **更新频率**：日更或隔日更，保证15秒～1分钟短视频，降低制作门槛

### 2. 内容选题库（永远不缺灵感）

所有选题来自你日常使用软件的过程，分成四个系列：


| 系列         | 选题示例                                                                      |
| ---------- | ------------------------------------------------------------------------- |
| **工具演示**   | “我写了个AI自动规划今日任务的脚本，看看效果” / “申论拍照AI批改，这分数靠谱吗？” / “用代码整理10年真题，发现资料分析必考这个公式” |
| **学习Vlog** | “在职备考第30天，今日学习2小时实录” / “周末摆烂后，我是如何用软件强制启动学习的” / “记录：刷题正确率从55%升到72%的那一周”   |
| **技巧分享**   | “一个提示词让AI帮你拆解申论材料” / “行测错题本这样用，复习效率翻倍” / “我的AI知识框架树，考前三天就用它”              |
| **心路历程**   | “程序员裸辞备考值得吗？” / “模考分数出来那一刻，我做了个决定” / “那些考公软件治好了我的拖延症”                     |


### 3. 录制与剪辑工具

- **录制**：OBS（免费，录屏+摄像头画中画）或 macOS自带QuickTime，手机可用自带录屏  
- **音频**：用软件直接内录系统声音+麦克风，初期不需要专业麦克，环境安静即可  
- **剪辑软件**：**剪映专业版**（全平台免费），功能足够  
- **统一模板**：在剪映里保存一个工程模板，固定片头、片尾、字幕样式、背景音乐，每次只替换核心内容，剪辑时间压缩到10分钟以内

### 4. 剪辑工作流（最简）

1. **粗剪**：将录屏拖入剪映，剪掉开头结尾的停顿和操作失误
2. **变速**：无解说的操作过程1.2～1.5倍速，讲解部分正常速度
3. **字幕**：使用剪映“自动识别字幕”，快速生成并校对
4. **BGM**：选择轻量纯音乐，音量调到10%以下，不干扰人声
5. **封面**：统一模板——左/上放标题大字，右/下放代码截图或学习界面截图
6. **导出**：1080P 30帧，码率推荐8Mbps

### 5. 标题与描述公式

- **标题**：数字+痛点+悬念  
  - “我用AI备考的第15天，行测正确率涨了12%”  
  - “在职每天学2小时，这是我做的AI规划软件”  
  - “申论拍照批改功能上线，AI给分比粉笔还严格？”
- **描述**：补全信息，包含关键词 #公考 #AI备考 #程序员考公 #学习打卡

### 6. 发布与运营

- **平台**：主攻**小红书**和**抖音**，同步分发到B站（程序员社区友好）  
- **发布时间**：晚上19:00～21:00（备考人群下班后刷手机高峰）  
- **互动**：每条评论必回复，引导关注  
- **引流**：视频中口播“这个软件是我自己写的，想体验的朋友可以私信我”，将意向用户沉淀到微信或社群

### 7. 进阶创意方向（未来）

- **系列化内容**：“30天用AI复习行测”每天一道题讲解  
- **挑战类**：“让AI给我出100道题，看我能对多少”  
- **数据可视化**：将每周正确率做成动态图表，比静态打卡图传播力强几倍

### 8. 克服“没经验”的心理关

第一条视频永远最粗糙。建议先做一个**15秒的屏幕录制**：打开你的软件，展示今日计划生成界面，配上字幕“我给自己写了个AI考公助手，今天开始记录备考”。发出去，就算起步。你的技术背景和真实备考经历就是最大的护城河，剪辑手法可以慢慢迭代。
