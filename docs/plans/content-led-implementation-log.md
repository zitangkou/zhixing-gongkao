# 内容运营驱动产品实施归档

> 建档日期：2026-09-07
> 适用产品：知行日知（时政学习）、知行策论（申论学习）
> 依据方案：`docs/products/content-led-launch-design.md`

## 1. 固定执行规程

每个开发单元严格按以下顺序推进：

1. 明确本单元目标、边界和验收条件。
2. 实施代码及必要文档修改，不混入其他未完成工作。
3. 完成自动化测试、静态检查和 H5／小程序构建等相应验证。
4. 在本文追加实施结果、实际能力、限制、验证证据和下一项。
5. 创建独立 Git 提交并推送到已确认远端。
6. 推送成功后自动进入下一项；遇到发布、密钥、外部发送或其他需要新增授权的动作时暂停确认。

“完成”只表示归档中列出的验收已通过，不代表已经部署、提审或公开运营。规划功能、代码功能、部署状态和平台发布状态分别记录。

## 2. 开发单元归档

### U01：时政文章免费学习闭环

- 状态：本地开发、验证、归档、提交与 GitHub 推送均已完成。
- 完成日期：2026-09-07。
- 本地提交：`0a4ffaa feat(theory): add guest article learning flow`。
- 产品范围：知行日知 H5、微信小程序、共用 FastAPI 后端。

#### 实际交付

- 未登录用户可以免费打开时政文章，选择“阅读全文”或“读重点”。
- 同一文章的已审核题目按每辑最多 5 题分组；题库完整时可以选择全文题目合集。
- 分辑与合集引用相同题目 ID，避免重复创建题目和错题身份。
- 单选、判断题点击后提交；多选题明确提交后才判定。
- 题面接口不返回答案、解析和原文依据；提交单题后才返回对应反馈。
- 游客作答及多选草稿按内容版本保存在当前设备；切换分辑、退出再进可以恢复。
- 内容版本变化后，旧页面停止继续判题并提示重新打开，避免新旧答案混判。
- 下线文章、未开放练习、待审核题和不完整题目不会进入公开合集。
- 今日页和复习页向游客提供文章学习入口，不再强制首次访问登录。
- 对外界面统一使用“时政学习”，产品名保持“知行日知”，主题配置统一为红色。

#### 数据与接口

- `GET /api/learning/articles/{article_id}`：返回已发布文章、无答案题面、分辑和内容版本。
- `POST /api/learning/articles/{article_id}/check`：校验内容版本、题目归属和选项后返回单题反馈。
- 两接口只允许 `X-Product-Key: theory`，不写账号积分、错题或阅读计数。
- 本地游客存储键包含文章 ID 和内容版本；当前尚未实现登录后的跨端合并。

#### 验证证据

- 后端相关测试：17 项通过，包括匿名分辑、答案隐藏、非法答案、跨产品隔离、内容下线和版本冲突。
- TypeScript：`tsc --noEmit -p apps/theory-app/tsconfig.json` 通过。
- ESLint：本单元相关页面、组件与 API 文件无错误。
- H5：`apps/theory-app` 的 `npm run build:h5` 通过。
- 微信小程序：`apps/theory-app` 的 `npm run build:weapp` 通过。
- 构建存在 Sass `@import` 和 legacy JS API 的上游弃用提示，不影响本次产物生成，后续作为工程升级事项处理。

#### 明确限制

- 游客记录目前只在本机保存，清理浏览器／小程序缓存会丢失；还不能登录后合并到账号。
- “读重点”暂使用文章已审核摘要，还没有独立的段落级重点标注结构。
- 当前分辑按稳定题目顺序每 5 题切分；运营后台还不能人工调整分辑、固定发布版本或标记长期重点专题。
- 尚未生成公众号、小红书、知乎、视频号的正式入口和运营发布包。
- 尚未部署、提审或公开发布。

#### 下一开发单元

`U02：申论学习公共三刀示范＋免费短练习闭环`。

目标是把已审核的三刀解剖作为公共教学示范展示，与用户个人练习隔离；未登录用户可阅读、完成短练习并在本机保存，不承诺 AI 评分。完成后按同样规程验证、归档、提交并推送。

### U02：申论学习公共三刀示范＋免费短练习闭环

- 状态：本地开发、验证、归档、提交与 GitHub 推送均已完成。
- 完成日期：2026-09-07。
- 提交：`96d9292 feat(shenlun): add guest three-cut learning flow`。
- 产品范围：知行策论 H5、微信小程序、共用 FastAPI 后端。

#### 实际交付

- 未登录用户可从“今日”或“精读”进入免费学习，不再因首次访问被强制送往登录页。
- 公共学习路径固定为三步：读原文、看三刀、做短练习；游客只看到当前已经开放的简单闭环。
- 公共示范沿用原版三刀字段和顺序：论证骨架包含总论点、分论点、论据、小结、论证方法、方法说明、套用模板与总结；规范表达包含规范词、经典金句和高频动词；万能句式包含原句、模板与仿写。
- 短练习支持字数范围、提交前自查、人工参考答案对照；未达到字数或未完成自查时不显示参考答案。
- 页面明确说明参考答案是教研对照而非 AI 评分，避免形成尚未实现的批改承诺。
- 游客答案、自查状态和是否已查看参考按文章与内容版本保存在当前设备；内容改版不会误恢复到新版本。
- 登录用户原有文章详情、复制全文、语料收集、个人三刀编辑器和个人记录仍保留；公共示范没有取代或改写原功能。
- 第三个底部页签的对外文案由“训练”统一为“练习”，与四栏统一导航规范一致。

#### 数据与接口

- 新增 `shenlun_teaching_examples` 公共教研示范表，按文章与版本唯一；它与含 `user_id` 的 `shenlun_mine_logs` 个人开采表严格分离。
- `GET /api/shenlun/learning/articles`：匿名返回具有完整已发布教研示范的文章列表。
- `GET /api/shenlun/learning/articles/{article_id}`：匿名返回原文、三刀示范、短练习和内容修订指纹。
- 两个接口只允许 `X-Product-Key: shenlun`；读取和本机练习都不会创建个人开采记录，也不会增加文章阅读计数。
- 草稿、下线文章、残缺论证点、空规范词、残缺句式或缺少短练习参考的内容均按失败关闭原则不进入前台。
- 新增 `server/scripts/import_shenlun_teaching_example.py`：从人工审核 JSON 导入，默认只建草稿；必须显式传入 `--publish` 才发布。
- 同一文章同一版本不允许用不同内容或状态覆盖；内容有变化必须升版本，避免线上教研内容被静默改写。
- 导入字段契约示例位于 `server/scripts/examples/shenlun_teaching_example.json`。

#### 验证证据

- 申论公共接口专项测试：12 项通过，覆盖匿名读取、原版字段、草稿与残缺数据拦截、文章下线、跨产品隔离、无个人记录副作用和版本指纹。
- 后端全量测试：158 项通过；现有 135 条警告来自 JWT 依赖的 UTC 时间弃用提示，不是本单元新增失败。
- TypeScript：`tsc --noEmit -p apps/shenlun-app/tsconfig.json` 通过。
- ESLint：本单元相关页面、路由配置与 API 文件无错误。
- H5：`apps/shenlun-app` 的 `npm run build:h5` 通过。
- 微信小程序：`apps/shenlun-app` 的 `npm run build:weapp` 通过。
- 双端构建仍有 Sass `@import` 和 legacy JS API 弃用提示，不影响本次产物。

#### 明确限制

- 本单元没有把云盘中的现有运营稿自动发布为公共教研示范；需按 JSON 契约人工复核并显式发布后，前台才会出现对应内容。
- 游客短练习只保存在本机，清理缓存或更换设备会丢失；尚未支持登录后合并与跨端同步。
- 当前公共短练习每篇一题，只提供结构化自查和人工参考，不含 AI 批改、分数或个性化建议。
- 公共教研示范目前通过安全导入命令维护，管理后台尚未提供可视化编辑、预览、审核与发布功能。
- 尚未部署、提审或生成带小程序码的渠道发布包。
