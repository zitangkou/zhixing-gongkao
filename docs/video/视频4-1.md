# 视频4

**视频拍摄全套落地指南（公考学习记录向）**

专为你这种「自己真实用软件学习 → 拍成每日短视频 → 推广软件 + 做视频号」场景设计，零经验可直接执行。重点放在**可复制、低负担、真实感强**。

---

### 1. 拍摄环境与背景

**核心原则**：干净、稳定、有「学习感」，避免杂乱抢戏。

**推荐三种场景（按优先级）**：


| 场景            | 适用          | 具体布置                                                             | 注意事项                        |
| ------------- | ----------- | ---------------------------------------------------------------- | --------------------------- |
| **桌面学习位**（主力） | 90% 日常视频    | 书桌干净，只留电脑/平板/手机 + 软件界面 + 一杯水/笔记本。背景墙面简洁（白/浅灰/木色），可放一盆小绿植或一本公考相关书 | 光线从左侧或正面自然光/台灯，避免逆光。桌面不要堆杂物 |
| **沙发/床边轻松位**  | 复盘、心情类、晚间总结 | 坐姿，背景是干净墙面或书架，灯光柔和                                               | 适合口播讲解，显得更真实放松              |
| **户外/阳台简拍**   | 偶尔换口味、打卡里程碑 | 简单背景，光线好即可                                                       | 噪音控制，别选太吵的地方                |


**光线建议**：

- 白天优先靠窗自然光（柔和、真实）。
- 晚上用台灯或环形灯（手机自拍灯也行），避免顶灯死白光。
- 人脸亮度略高于背景，软件界面清晰可见。

**背景禁忌**：杂乱衣服、脏乱桌面、强烈反光、晃动窗帘、明显品牌logo墙。

---

### 2. 拍摄角度与构图

**推荐三种固定机位（形成个人风格）**：

1. **正面口播 + 屏幕录制混合**（最常用）
  - 手机竖屏架在桌面支架上，高度与眼睛平齐或略高。
  - 构图：人脸占画面上方 1/3～1/2，下方或侧边留空间后期叠加软件录屏。
  - 适合：讲解思路、复盘错题、分享心得。
2. **纯屏幕录制 + 画中画人脸**（软件演示向）
  - 先录软件操作（Taro H5 或小程序界面），再在剪映里加小窗自己的脸。
  - 适合：展示刷题流程、资料分析专项、申论开采、足迹页等。
3. **俯拍桌面**（偶尔用）
  - 手机从正上方拍手操作平板/手机的过程。
  - 适合：快速展示「今日任务完成」或写笔记瞬间。

**固定习惯**：

- 始终竖屏（视频号主战场）。
- 人脸尽量清晰、眼神看镜头或看屏幕（自然即可）。
- 不要频繁晃动手机，用支架。

---

### 3. 时长建议


| 类型        | 推荐时长             | 说明             |
| --------- | ---------------- | -------------- |
| 日常学习记录    | **25–45 秒**      | 完播率最高，适合每日更    |
| 方法拆解 / 技巧 | 45–60 秒          | 讲清楚一个点即可       |
| 周总结 / 里程碑 | 60–90 秒          | 可稍长，但前 3 秒必须抓人 |
| 测试期       | 先统一卡在 **35 秒左右** | 方便你形成节奏感       |


**黄金结构**（无论长短都用）：

- 0–3 秒：强钩子
- 3–25 秒：核心过程/内容
- 最后 5–8 秒：总结 + 行动号召 + 软件露出

### 4. 背景音乐（BGM）

**原则**：轻、不抢人声、有轻微节奏感，情绪匹配「专注/进步」。

**推荐风格**：

- 轻快钢琴 / 轻电子 / 学习向 Lo-fi
- 避免：强节奏DJ、悲伤钢琴、网络热门魔性BGM（容易同质化且版权风险）

**剪映实操**：

- 搜索「学习」「专注」「轻快钢琴」「励志轻音乐」
- 音量调到人声的 20–30%，保证说话清晰
- 可固定用 2–3 首作为你的「招牌BGM」，形成听觉记忆

后期有一定播放量后，可考虑正版音乐或剪映商业授权。

### 5. 固定开头（强烈建议做成个人IP符号）

每天视频前 3 秒保持高度一致，观众一眼就知道是你。

**推荐固定开头模板**（选一个坚持用）：

**版本A（数据型，推荐）**：
「今天是备考第 X 天，用知行刷题正确率 XX%。」

**版本B（行动型）**：
「开始今日公考学习，先打开知行。」

**版本C（问题型）**：
「资料分析又卡壳了？今天这样破。」

配合动作：

- 举手示意 / 指向屏幕 / 打开软件首页
- 或者直接切入软件界面 + 大字幕

字幕同步出现大字标题（例：「第47天｜资料分析正确率78%」）。

### 6. 话术脚本与情景模式

把内容分成固定「情景模式」，每种模式有标准话术框架，降低创作压力。

#### 情景模式一：每日学习记录（主力，建议占60%）

**结构**：

1. 固定开头（数据）
2. 今天重点做了什么（1–2 个模块）
3. 过程中的一个真实感受/发现
4. 结尾：展示足迹或积分 + 行动号召

**示例脚本**：
「今天是备考第52天。用知行做了资料分析专项，20题正确率85%。中间有两道增长率比较差点算错，后来用软件里的秒杀技巧直接秒了。现在打开足迹看，本周已经刷了对应薄弱点。明天继续攻数量关系。一起坚持。」

#### 情景模式二：方法/技巧拆解

**结构**：提出痛点 → 展示软件对应功能 → 演示一步 → 结果对比

**示例**：
「很多人资料分析算到最后才发现单位错了。我现在养成习惯，先看软件公式库对应的白话释义，再动手。今天这道题用这个方法，30秒出结果。」

#### 情景模式三：错题/复盘

「今天错了3道申论规范词相关题。打开错题本，把考点挂到知识框架上，系统已经自动排了复习。以前错题就放着，现在闭环了。」

#### 情景模式四：周总结/里程碑

「这周用知行累计学习X小时，正确率从XX%提到XX%。最大的变化是……下周目标是……」

#### 情景模式五：软件功能演示（推广向，控制频率）

自然融入，不要硬广。例：「以前找时政文章很散，现在首页直接推今日必读，读完还能直接练题。」

### 8. 拍摄与后期小建议（降低负担）

- **拍摄**：每天学习时顺便录，不要专门「表演学习」。真实操作过程最有说服力。
- **录音**：尽量安静环境，口播清晰即可，卡壳重录那一句就行。
- **后期（剪映）**：
  - 自动字幕 + 手动改关键词加粗/变色
  - 关键软件界面时加进度条或高亮圈
  - 结尾统一加固定字幕「知行公考｜读得进，练得出」
  - 导出竖屏 1080×1920
- **发布**：固定晚上时段，标题用数字+痛点（「第52天，资料分析正确率提升了」），话题加 #公考打卡 #行测 #申论 #资料分析

### 执行节奏建议（从零开始）

1. 先选定「桌面学习位」+「固定开头版本A」。
2. 连续拍 7 天「每日学习记录」，只求完成，不求完美。
3. 第 8 天开始加入 1 条方法拆解。
4. 每周日做一条周总结。
5. 把你常用的 3–5 个脚本存成备忘录，直接替换数字和内容。

这样你能把「学习」和「拍视频」几乎融合成一件事，负担最小，真实感最强，也最符合你想打造的「自己学习进步 + 软件完善 + 视频号增长」正循环。

目标只有一个：**把真实刷题过程拍成短视频**，负担最小化，可长期坚持。其他内容（方法拆解、周总结等）以后再加。

### 1. 环境背景（越简单越好）

**唯一推荐场景：固定桌面学习位**

- 位置：你平时刷题的那张桌子，不要换地方。
- 桌面只留三样东西：
  1. 手机/平板（打开知行刷题界面）
  2. 一杯水或一个杯子（增加生活感）
  3. 一支笔或一本薄本子（可选）
- 背景：干净墙面或浅色窗帘即可。把杂物全部挪开，拍完再放回去。
- 光线：白天靠窗，晚上用一盏台灯从左侧或正面打光（手机自带补光灯也够用）。

**创新小技巧**：

- 在桌角固定贴一张小纸，写「今日刷题」四个字，每天入镜一次，形成视觉记忆点。
- 如果桌面实在乱，就用一张浅色桌布或A4纸垫在设备下方，瞬间变干净。

---

### 2. 拍摄角度（固定一种就够）

**主力角度：手机竖屏支架 + 斜上方45度俯拍桌面**

- 用便宜手机支架（或书本叠起来）把手机固定在桌子斜上方。
- 画面里同时出现：你的手操作屏幕 + 软件界面 + 你的半张侧脸或手部动作。
- 不需要正脸出镜，降低心理压力，也更真实。

**备选角度**（偶尔换着用）：

- 纯屏幕录制（手机自带录屏）+ 后期加极小的人脸小窗（可选）。
- 正面口播（只在结尾总结时用几秒）。

**创新点**：每天固定同一个支架位置和高度，观众会产生「熟悉的学习角落」的感觉，增强辨识度。

---

### 3. 时长（严格卡死，保护精力）


| 学习时长    | 视频成品时长      | 说明         |
| ------- | ----------- | ---------- |
| 30 分钟刷题 | **25–35 秒** | 最推荐，完播率高   |
| 1 小时刷题  | **35–50 秒** | 最多不超过 55 秒 |


**黄金结构（必须遵守）**：

- 0–3 秒：固定开头
- 3–25 秒：刷题过程精华
- 最后 5–8 秒：结果 + 一句话总结

每天只剪这一个长度，形成肌肉记忆。

---

### 4. 背景音乐（固定 1–2 首即可）

- 风格：轻快但不嘈杂的钢琴或轻电子（剪映搜「专注学习」「轻快钢琴」「lofi study」）。
- 音量：人声清晰的前提下，BGM 只保留 15–25%。
- **创新做法**：选定两首作为「刷题专属BGM」，一首用于正确率较高的日子，一首用于复盘错题的日子。观众听声音就知道今天状态如何。

### 5. 视频固定开头（做成你的个人符号）

每天前 3 秒必须一模一样，形成条件反射。

**推荐固定开头（二选一，选定后绝不换）**：

**版本A（数据直接型，最推荐）**  
画面：软件刷题首页或今日任务页  
字幕大字：第XX天 · 刷题XX道  
口播：「备考第XX天，开始今日刷题。」

**版本B（动作型）**  
画面：你的手点击进入刷题模式  
口播：「打开知行，开始刷题。」  
字幕同步出现「第XX天」

配合一个小动作：每天开头都用同一根手指点击屏幕，形成视觉锚点。

### 6. 情景模式（只做这 3 种，足够用）

每天根据刷题情况，只选其中一种拍，绝不复杂化。


| 情景模式          | 适用情况            | 核心记录点              | 建议频率     |
| ------------- | --------------- | ------------------ | -------- |
| **模式1：正常刷题流** | 普通练习日           | 做题过程 + 最终正确率       | 每周 4–5 天 |
| **模式2：错题复盘流** | 错题较多或重点突破日      | 错题界面 + 为什么错 + 如何标记 | 每周 1–2 天 |
| **模式3：专项突破流** | 集中练某一个题型（如资料分析） | 进入专项 → 做题 → 结果对比   | 每周 1 天   |

### 7. 话术脚本与完整剧本（直接复制使用）

#### 模式1：正常刷题流（最常用，25–35秒）

**【0–3秒 固定开头】**  
「备考第XX天，开始今日刷题。」

**【3–20秒 过程】**

**【20–35秒 结果】**  
（画面：结果页正确率 + 足迹或积分）  
口播：「正确率XX%。已经标记到错题本。明天继续。一起打卡。」

#### 模式2：错题复盘流（30–40秒）

**【0–3秒】**  
「备考第XX天，今天重点复盘错题。」

**【3–25秒】**  
（画面：错题本界面 + 某道错题解析）  
口播：「这道资料分析增长率比较，我又把单位看错了。已经在软件里关联到对应考点，系统会自动安排复习。」

**【25–40秒】**

**【0–3秒】**

**【3–30秒】**  
（画面：进入专项练习 → 材料展开 → 做题 → 计时）  
口播：「今天集中练增长量比较，用了软件里的秒杀技巧，平均每题控制在50秒以内。」

**【30–45秒】**  
「正确率从之前的70%提到了XX%。专项就是要这样死磕。明天换数量关系。」

### 8. 每日执行极简流程（真正能坚持的版本）

1. 开始刷题前，把手机架好（固定位置）。
2. 打开知行，点击录屏或开始拍摄（也可以刷完再补录关键界面）。
3. 正常刷题 30–60 分钟，过程中不用管镜头。
4. 刷完后，花 **5–8 分钟** 做后期：
  - 剪掉废话和停顿
  - 加上固定开头字幕
  - 贴上正确率大字
  - 加BGM
  - 导出
5. 当天或次日发布。

**创新减负技巧**：

- 提前在剪映存好「固定开头模板」和「结尾字幕模板」，每天只替换数字。
- 正确率、题量这些数据，直接从软件结果页截图贴上去，比口播更直观。
- 如果某天实在不想出镜，就纯屏幕录制 + 字幕讲解，也完全成立。
