# 视频1

好的，我们把镜头对准你的书桌和屏幕，从零开始，搭建一个完整的“程序员考公视频工厂”。下面的方案会具体到你今天就能拍出第一条视频。

### 一、环境与背景：打造“沉浸式学习”视觉锤

你的视频背景，就是你的个人符号。**坚持“一个固定场景，百变内容”**，让观众一看到这个画面就知道是你。

- **场景选择**：书桌角落，最好是靠墙的一面，这样可以减少杂乱。背景墙保持干净，可以贴一张你打印的“艾宾浩斯遗忘曲线表”或一张手写的“上岸”便签，这是最好的软装。
- **核心道具**：
  - **主屏幕**：你的电脑显示器或大屏iPad，这是视频的绝对主角。
  - **副道具**：一杯水、一个计时器（用手机App显示）、一支笔和一本摊开的笔记本。这些道具传递“正在学习”的状态。
  - **设备架设**：用一个简单的手机支架，固定在桌面左侧或右侧，用**俯拍或45度角**拍摄桌面。这能拍到屏幕，也能拍到你的手在写写画画，既有科技感又有学习氛围。
- **灯光（最关键的一步）**：白天自然光足够，晚上请务必保证光线充足。一个小技巧：**屏幕亮度调高，屏幕就是你的主光源**。可以在屏幕后方贴一条便宜的LED暖光灯带，照亮背景墙，制造景深感。避免头顶直射的苍白顶灯。

### 二、拍摄参数与BGM：建立统一质感

- **画幅与角度**：
  - **纯屏幕操作（如演示软件、敲代码）**：直接录屏。这是你最常用的角度。
  - **真人出镜（可以不露脸）**：手机俯拍桌面，只拍到你的手、键盘、屏幕和桌面环境。这是“学习Vlog”的角度。
  - **画中画模式**：剪辑时，主画面是录屏，角落小窗放俯拍桌面镜头。
- **时长控制**：
  - **快速演示/打卡类**：15-30秒（抖音/小红书极速版）。
  - **方法分享/心路历程类**：1-2分钟。
  - **完整学习Vlog**：控制在3分钟内，用快进剪辑展现。
- **背景音乐（BGM）**：
  - 在小红书/抖音的音乐库搜索 **“学习歌单”、“轻音乐”、“白噪音”**。
  - 推荐风格：轻柔钢琴（如Kevin Kern）、Lo-fi Hip Hop、图书馆白噪音（翻书声、写字的沙沙声）。
  - **关键**：背景音乐音量降至 **10%-15%**，永远不要盖过人声。

### 三、固定开头与口播脚本：形成个人标签

你需要3个“一句话”固定开场白，根据视频类型选择，立刻抓住观众。


| 视频类型      | 固定开头（口播/字幕）                         | 话术脚本框架                                                                                                                              |
| --------- | ----------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| **软件演示类** | **“看一个程序员，怎么用自己写的App，搞定(具体问题)。”**   | 1. **抛出痛点**：比如，“行测错题整理太费时间了。” 2. **演示解法**：录屏演示你软件的一键错题拍照上传功能。 3. **效果对比**：展示AI整理好的错题本。 4. **结尾引导**：“这个功能我刚写完，想试试的可以告诉我。”            |
| **学习日常类** | **“在职备考第(天数)天，今日学习(时长)小时，这是我的记录。”** | 1. **展示计划**：打开软件，展示AI生成的今日任务清单。 2. **快进学习**：15秒快进你做题、看课、记笔记的画面。 3. **成果展示**：软件显示今日打卡完成，正确率变化。 4. **今日感悟**：一句话感受，如“数量关系还是头大，明天重点攻关。” |
| **技巧心法类** | **“一个让申论效率翻倍的AI隐藏用法。”**             | 1. **悬念切入**：展示一堆密密麻麻的申论材料。 2. **分步骤展示**：1. 拍照； 2. 输入指令“总结核心要点及论证框架”； 3. AI输出结果。 3. **升华价值**：“这就把被动阅读变成了主动拆解，节省的时间可以多练两道小题。”         |


### 四、情景模式与剧本：三个今日可拍的剧本

这是为你量身定做的三个剧本，直接照着拍。

#### 剧本一：《AI规划师 vs 摆烂周末》

**目标**：解决你“周末松散”的痛点，引发共鸣。
**情景**：周六早上，你坐在书桌前发呆，不知道学什么。
**拍摄流程**：

1. **镜头1（俯拍）**：手机支架俯拍，你看着手机，打开你的软件，点击“生成今日随机挑战任务”。（字幕：“周末不知道怎么开始？让程序给我安排”）
2. **镜头2（录屏）**：屏幕显示软件弹出一个任务：“【挑战】限时15分钟，完成10道资料分析真题，正确率需超70%”。（配音效“叮”）
3. **镜头3（混合快剪）**：15秒快剪。你开始做题（手在纸上演算的画面），时间在走。背景音乐有节奏感。
4. **镜头4（结果）**：录屏显示“挑战成功！正确率80%”。（配音效“Victory！”）
5. **镜头5（口播）**：你拿起手机对着屏幕拍一张，说：“这种随机任务的机制，治好了我的选择困难症。今天这小节就算学完了，剩下的时间安心休息。”

#### 剧本二：《AI申论判卷官上线》

**目标**：突出你软件的核心功能，吸引精准用户。
**情景**：你刚写完一道申论小题，想看看自己的水平。
**拍摄流程**：

1. **镜头1（口播+展示）**：你举着一张手写好的申论答案，对准镜头。“这是我刚写的答案，我们来看看我的AI判卷官怎么说。”
2. **镜头2（录屏）**：手机拍照，在软件里上传照片。屏幕显示“识别中...” → “批改结果”。
3. **镜头3（录屏详解）**：滑动查看AI评分和建议：“得分点：80%；逻辑分：良好；格式分：优。建议：遗漏了‘加强监管’这个要点，可补充表述。”（字幕划重点）
4. **镜头4（口播）**：你回到镜头前，震惊又认真的表情。“有点严格，但确实一针见血。这个方法最大的好处，是能让我立刻知道自己的答案缺点在哪儿，不用等老师判卷。”

#### 剧本三：《程序员的学习黑科技》

**目标**：强化你“程序员+考生”的独特人设，拉满好奇心。
**情景**：你在敲代码，不断完善你的软件。
**拍摄流程**：

1. **镜头1（俯拍屏幕）**：你的代码编辑器（Cursor）占满屏幕。标题大字：“今天给自习室添了个‘自律buff’”。
2. **镜头2（录屏）**：你快速敲击键盘，屏幕上出现一行核心代码，然后切换到软件界面。你点击一个新按钮：“生成学习周报”。
3. **镜头3（录屏展示）**：软件迅速生成一份精美的周报，包含“本周正确率趋势图”、“薄弱知识点预警”、“下周学习重心建议”。
4. **镜头4（口播）**：你看着屏幕，满意地笑一下（不露脸，肩部即可）。“别人花钱买课，我给自己写了个学习外挂。下期想看啥功能，评论区告诉我。”

### 五、从“废片”到“作品”的剪辑清单

打开剪映，按照这个清单做，10分钟内出片：

1. **导入素材**：把你拍的视频片段和录屏文件全拖进去。
2. **粗剪排序**：把拖沓的开头、结尾、口误、操作失误的部分剪掉。按剧本顺序把片段排好。
3. **倍速播放**：无解说的纯学习、敲代码画面，调整到 **1.5 - 2倍速**。有口播的地方正常速度。
4. **自动字幕**：点击“文本”→“智能字幕”→“识别字幕”，瞬间生成字幕。你需要做的只是快速检查一遍错别字，修改一下专有名词。
5. **加持BGM**：点击“音频”→“音乐”，搜索你喜欢的“轻音乐”，添加后把音量拉到10%以下。
6. **套用封面模板**：把你的第一条视频剪辑工程，另存为“我的模板”。以后每次制作，直接套用，替换核心内容即可。封面统一为：左半边是软件或学习实拍图，右半边是三个大字标题（如：“AI批改”、“周末挑战”）。

你的第一条视频，可以先从《剧本一》开始。因为它的核心就是对抗你最真实的痛点，这种“真实”比任何花哨的剪辑都更打动人。你不需要等到软件完美，你“正在优化”这件事本身，就是最精彩的故事。

 

你把这个方向聚焦到“每天30-60分钟的刷题记录”，是非常精准的判断。这不仅解决了你时间不足的问题，更塑造了一个极其专注、易于持续的内容定位。

我们就在这个限定条件下，把所有环节设计到极致。核心策略是：**不拍学习，拍“用工具打怪”；不拍过程，拍“数据与反馈”。**

### 一、环境与背景：打造“程序员的作战指挥台”

你的环境不是自习室，而是一个**数据监控中心**。

- **固定机位**：手机用支架固定在桌面左侧或右侧，采用**45度俯拍角度**。画面要清晰地同时拍到你的**电脑屏幕**、**键盘和鼠标的手**、以及**桌面一角的一杯水**。这个角度同时有“科技感”和“沉浸感”。
- **背景（代码墙）**：不要贴在白墙上。想办法让电脑屏幕后面的墙“说话”。可以贴两张A4纸，一张打印着“**今日Bug：0**”，另一张打印着“**上岸倒计时：XX天**”。或者，用便利贴拼成一个“**上岸**”的字样。这是完全属于程序员的软装。
- **核心光源（屏幕光）**：把房间的顶灯关掉。只保留电脑屏幕的光和屏幕背后一个廉价的LED暖光小台灯，照亮背景墙。光线有明暗对比，会让视频质感瞬间提升一个档次。你刷题时，屏幕的光映在你手上和键盘上，很有感觉。

### 二、拍摄参数与BGM：用“ASMR”思维做声音

- **画面与时长**：
  - **主画面（90%时间）**：**直接录屏**。你的软件刷题界面，是比任何书桌都更精彩的内容。
  - **画中画（画龙点睛）**：剪辑时，在录屏画面的角落（比如右上角）放一个小框，是你对着屏幕的脸的反应，或者就是你手敲键盘的特写。**时长控制在45-75秒**。
- **背景音乐（BGM）的“三不原则”**：
  - **不抒情**：不要用有强烈情感旋律的钢琴曲。
  - **不嘈杂**：不要用带人声的歌曲。
  - **不随意**：固定使用一首或三首，形成你的声音符号。
  - **推荐风格**：**Lo-fi Hip Hop** （最推荐，天生带“程序员熬夜刷题”的冷静感）、**极简电子/氛围音乐** （如 《Weightless》 类型的音乐）。
  - **更高级的声音设计**：**加入音效**。鼠标点击声（哒）、键盘敲击声（清脆的机械音）、软件答对题的提示音（叮）、答错题的音效（低沉一声）。这些“实景音效”比BGM更吸引人，是ASMR的核心。

### 三、固定开头与话术脚本：一句定“人设”

你需要一句像代码一样精准的开场白，让观众1秒内就知道你是谁。

**固定开场白：“公考程序员，每日一测。Bug要修，题也要刷。”**

这句话把你的两个身份完美融合，而且充满动态感和幽默感。每次视频开头，无论是口播还是用浑厚的电子音配音，都用这句话。

**针对刷题的话术框架（每题一个闭环）：**
你不需要讲整张卷子，每次只讲1-2道题。遵循 **“人类读题 → AI解析 → 我的思考”** 三步法。

- **话术示例1（做对一道难题）**：
（播放录屏，鼠标选中一道题）“这道逻辑填空，正确率只有28%。我的第一反应是选C。”（稍停，点击“查看AI解析”）“看了一下AI的解析，它认为空在转折之后，要与‘孤芳自赏’构成反义，所以‘融会贯通’是唯一选项。”（回到你口播或画中画表情）“逻辑线条非常清晰，这比查书快多了。拿下。”
- **话术示例2（做错一道不该错的题）**：
（播放录屏，显示大大的红叉和你的错误选项）“资料分析，算到第三步，栽在单位陷阱上了。”（点击“加入错题本”，再点“AI解法对比”）“AI直接把我的计算步骤和标准步骤并列对比，红色标出了我跳进坑的那一步。”（你叹口气）“这个坑，AI只能指给你看，下次跳不跳，得靠自己了。标记一下，明天重做。”

### 四、情景模式与剧本：三个可直接开拍的“刷题剧”

#### 剧本一：《30分钟刷题挑战》

- **内容**：记录你下班后，打开软件，完成一个由AI生成的“今日特训包”（10-15道题）。
- **拍摄**：
  1. (5秒) 俯拍你打开软件，点击“开始今日挑战”。计时器开始倒计时30:00。
  2. (40秒) 快剪/快进。屏幕快速闪过你作答的题目，背景是你认真敲击键盘和按鼠标的声音。可以加速到2-3倍速。
  3. (15秒) 挑战结束。屏幕显示成绩：正确率、用时、错题列表。
  4. (10秒) 画中画窗口出现你疲惫但满意的脸，你喝了一口水，说：“今天正确率85%，收工。”

#### 剧本二：《一道题教会我的事》

- **内容**：聚焦一道你做错的错题，演示你如何用软件的工具彻底搞懂它。
- **拍摄**：
  1. (10秒) 录屏，打开错题本，鼠标悬停在一道标红的错题上。配音：“每日一个避坑小技巧，今天从这道图推题说起。”
  2. (30秒) 录屏，你用软件的“搜索同类题”功能，瞬间调出3道同考点的题目。展示你把它们一次性做完并全对的过程。这展示了工具强大的归纳和练习能力。
  3. (10秒) 你这道题的笔记自动保存到了“知识框架-图推-位置类”节点下。展示这个知识点树逐渐丰满的样子。
  4. (5秒) 口播：“让错题长成一棵树，而不是堆成垃圾堆。”

#### 剧本三：《与AI辩经》

- **内容**：你坚持认为自己的答案有道理，向AI解析发起“挑战”，记录这个过程。
- **拍摄**：
  1. (10秒) 你对着一道被批错的题，皱眉。口播：“这道题，我不同意AI的解析。我们来开个issue。”
  2. (30秒) 录屏，你在软件的问题反馈入口，打字或语音输入你的理由和逻辑。
  3. (15秒) 系统反馈：“根据你的思路，推荐查阅 知识点：XX”。你点击查看，然后露出恍然大悟或坚持己见的搞笑表情。
  4. (10秒) 口播：“人机对战，暂时1：1。明天继续Battle。保持质疑，正是学习的开始。”

### 五、剪辑清单（确保10分钟搞定）

为这个“日更刷题”视频定一个死规矩：**只用剪映，不超过5个步骤，10分钟内必须导出。**

1. **粗剪**：拖入今天的录屏。把刷题开始的准备动作和结束后的发呆时间剪掉，只留下“开始答题”到“成绩展示”的核心部分。
2. **设置倍速**：将中间的答题过程整体设置为1.8倍速。保留你查看解析和发表感想的部分为正常速度。
3. **聚焦重点**：当需要展示AI解析的详情时，用“**缩放**”功能，把画面局部放大到200%，让观众看清你屏幕上的字。这比任何解说都直观。
4. **套用声音**：第一段轨道放你固定的BGM，音量10%。第二段轨道放你视频原声，把“鼠标点击音”和“机械键盘敲击音”的音量适当放大。第三段轨道放AI朗读出来的开场白或解题要点（剪映的文字转语音功能）。
5. **统一封面**：在你的“模板”里修改今日标题，如 “Bug 修到一半，刷10道题冷静下”、“打卡第X天 | 今日正确率78%，波动有点大”。

从“一道题”开始拍，你拍的不是学习，是产品Demo演示，是你自己与一个自研学习系统的交互日志。这件事，只有你能做。
