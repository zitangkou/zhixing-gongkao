## 1. 一句话定位

> 一个以"上岸"为唯一目标的**公考个人成长操作系统**——学 → 练 → 测 → 复 → 分享，所有学习行为自动沉淀为可分享的备考记录。

差异化三件套（市面产品没有的组合）：

1. **完整闭环**：阅读 → 框架 → 练习 → 复盘 → SRS 复习，不是题库堆砌；
2. **申论垂直深耕**：人民日报三刀解剖 + 规范词 + 阶梯训练是独有资产；
3. **真实养成叙事**：开发者本人即第一用户，App 成长与备考过程全程公开（视频号），产品自带内容飞轮。

**功能取舍唯一标准**：是否直接服务笔试/面试提分，或服务"坚持学习"本身。

## 2. 三大使命

| # | 使命 | 落地设计 |
| --- | --- | --- |
| 1 | **自用备考**：我是第一用户，每天用它学习 | 「今日」驾驶舱驱动日闭环；M2 起每天真实使用 |
| 2 | **视频号联动**：学习记录做视频，自我督促 + 引流 | 上岸卡片自动生成，学完即出图、出图即素材 |
| 3 | **社区化铺垫**：从单机工具演进为备考社区 | v1 预埋 activity_event，社区 = 事件的"读取视图" |

**增长飞轮**：

```
我备考 → 开发/打磨软件 → 每日学习数据 → 视频号内容
   ↑                                          ↓
产品完善 ← 社区沉淀 ← 用户进入 App ← 内容引流
```

**节奏原则**：M2 起每天用新应用学习（哪怕不全），应用完善与备考同步——使命 1 的落地方式。
**视频号从 M0 当天就开始**（用现有知行素材即可发第一条，不等 App）。

## 6. 范围与边界（v1 严格收敛）

### 6.1 必须做（v1 必交付）

- 14 个后端域迁移（auth/user/article/question/exam/ziliao/knowledge/review/rmrb/corpus/plan/events + signin/points/rank/growth/feedback）
- 6 个后端域**全删**：english / dushu / health / ledger / wealth / recharge
- 4 Tab 骨架（今日/学习/练习/我的）
- 今日驾驶舱（倒计时 + 今日任务 + 到期复习 + 昨日数据条 + 上岸卡片入口）
- 上岸卡片生成器（5 类：今日打卡/周报/里程碑/成绩/开采）
- 能力雷达图（行测五模块 + 申论）
- activity_event 表 + 写入点（v1 不暴露 UI）
- 视觉系统（深蓝主色 + 暗色模式 + 4 Tab 图标位）
- 个人公考数据导出导入（一次性）

### 6.2 明确不做（v1 不做）

- 社区 UI（v2 才有）
- AI 解析 / 申论批改（v1.5+）
- 拍照 OCR 转知识点（v2+）
- 智能组卷（v1.5+）
- 资料共享 / 互批申论（v3+）
- 会员中心（占位即可）
- 充值（直接砍）

### 6.3 灰度评估（v1 末尾决定是否升 v1.5）

- AI 题目讲解
- 智能组卷
- 申论 AI 预批改
