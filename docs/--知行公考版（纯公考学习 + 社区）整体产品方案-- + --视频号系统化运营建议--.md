**知行公考版（纯公考学习 + 社区）整体产品方案** + **视频号系统化运营建议**

产品定位清晰：只服务公务员考试（行测 + 申论 + 时政 + 面试基础），去掉英语、读书、健康、账本、财富等所有非公考模块。保留并强化现有公考相关能力，同时加入真正可运营的社区，方便后期用户增长与内容沉淀。技术栈可直接复用现有 Taro 4 + Vue 3（H5/小程序）+ FastAPI + Admin + SQLite，降低迁移成本。

### 一、产品定位与命名建议

- **产品名建议**：知行公考 / 行知公考 / 公考知行
- **Slogan**：读得进，练得出，考得上
- **一句话**：以行测+申论+时政为主线的个人高效学习系统 + 公考社区，帮你把碎片时间变成真正进步。
- **核心用户**：在职/在校备考省考、国考、事业单位的考生；后期可扩展面试、选调。
- **差异化**：不是题库堆砌，而是「阅读 → 框架 → 练习 → 复盘 → 社区沉淀」完整闭环 + 艾宾浩斯复习 + 真实用户学习轨迹。

### 三、核心功能模块设计（基于现有能力强化）

**1. 学习首页**

- 品牌 Banner + 积分/连续学习天数
- 今日必做：复习任务数、计划清单、推荐时政
- 公考主线快捷入口（时政、资料分析、申论、知识框架、真题套卷）
- 社区热帖/今日精华预览（吸引进入社区）
- 上拉推荐时政文章

**2. 时政阅读**

- 保留现有：正文 + 目录 + 分节进度 + 思维导图 + 读完刷题
- 强化：文章与知识框架双向关联、重点段落一键采集到「规范表达库」

**3. 资料分析**

- 完整保留：公式库（KaTeX）、题型库、秒杀技巧、专项练习（材料折叠 + 计时 + 结果解析）
- 增加：个人薄弱题型统计 + 一键进入对应专项

**4. 申论 · 人民日报**

- 保留：时评列表/详情（结构化解剖）、开采本、规范词库、阶梯训练（造句/仿写/口述）
- 强化：开采记录可一键分享到社区「今日开采」；规范词可标记「我已掌握」并进入复习

**5. 知识框架**

- 多棵考点树（行测各科 + 申论要素 + 时政热点）
- 节点备注、星标、掌握度、SRS 复习
- 支持 Obsidian Markdown 同步（管理端上传）

**6. 练习闭环（练习 Tab）**

- 模式：今日精选 / 随机 / 时间线 / 重点突破 / 按文章练 / 错题重练 / 套卷
- 行测错题本（手动录入 + 拍照 + 考点关联 + 掌握标记）
- 文章错题本
- 复习中心：聚合所有到期任务（错题 + 知识点 + 规范词）

**7. 真题套卷**

- 真题 / 模拟 / 自定义
- 限时作答 → 交卷 → 成绩 + 详细解析 + 历史对比

**8. 学习计划 & 事件复盘**

- 今日清单（完成/跳过/备注）+ 日复盘（完成度、弱项、明日重点、心情）
- 本周总览
- 事件复盘：记录模考、面试模拟、重大节点，可挂载知识点

**9. 社区（全新重点，为增长与留存服务）**

- **动态广场**：图文/短文字动态，支持话题标签（#资料分析秒杀 #申论开采 #今日打卡）
- **专题频道**：行测讨论、申论写作、时政热点、经验分享、答疑专区
- **学习打卡**：一键分享今日足迹（刷题数、正确率、阅读时长、开采记录），生成精美卡片
- **互动**：点赞、评论、收藏、关注用户
- **精选机制**：管理员/算法推荐高质量经验帖置顶
- **积分激励**：发帖、被赞、被收藏、连续打卡均可获得积分（与学习积分打通）
- **后续可扩展**：小组、模考成绩晒分、互相批改申论（人工审核）

**10. 我的 · 成长**

- 签到日历、积分流水、刷题排行（日/周/月/总）
- 知行足迹：本周分钟、正确率、各模块进度条、投入柱状图
- 个人资料、反馈、深色模式
- 充值（初期可先 mock，后期接真实支付做会员/题库扩展包）

### 五、布局、交互与视觉原则（做成真正产品的关键）

- **视觉**：品牌红 `#D0021B`（亮）/ `#E85D6A`（暗），大量留白 + 清晰层级，避免信息过载。深色模式完整支持。
- **首页**：Banner 不占太多高度，今日任务卡片突出，主线入口用图标+文字网格（2–3 列）。
- **练习流**：答题页极简（题干 + 选项 + 底部导航），交卷后结果页强反馈（正确率 + 排名 + 积分动画）。
- **社区**：信息流卡片式，支持图片，评论抽屉，发帖入口常驻底部或悬浮。
- **交互统一**：
  - 全局 Toast / Confirm 走统一反馈组件
  - 表单保存前强制 flush 语音输入
  - 导航封装，禁止直接跳转混乱
  - 列表上拉分页 + 骨架屏
- **移动端优先**：小程序 + H5 双端，底部 Tab 固定，重要操作一屏完成。
- **性能**：图片懒加载、公式按需渲染、社区流虚拟列表。

技术侧继续沿用现有共享组件（KnowledgeTree、LatexBlock、MindMap、QuestionItem、SignCalendar、VoiceInputBtn 等），社区新增 PostCard、FeedList、TopicTag 等。

### 八、视频号系统化制作与运营建议（零经验可落地）

目标：用「自己真实用软件学习」的过程，做成有价值、可复制、能引流到产品的内容，同时记录个人成长。

**1. 内容支柱（每周固定结构）**

- **每日学习记录**（主力，占 60%）：今天用软件刷了什么、开采了哪篇、错题复盘、正确率变化。真实、有过程。
- **方法拆解**（20%）：资料分析某个秒杀技巧、申论开采模板、知识框架怎么建。
- **成果/对比**（10%）：周总结、模考前后对比、连续打卡里程碑。
- **产品相关**（10%）：软件新功能演示、使用小技巧、用户反馈回应（后期）。

**2. 每日生产流程（可坚持的节奏）**

1. 早上/晚上固定 30–60 分钟真实学习（用软件）。
2. 学习过程中随手截图关键节点（刷题界面、正确率、开采本、思维导图、足迹页）。
3. 用手机录 1–3 分钟口播或屏幕录制（讲解思路即可，不需要完美）。
4. 剪辑 15–60 秒成片（见下方工具）。
5. 当天或次日发布，固定时间（建议晚上 8–10 点或中午）。

**3. 工具推荐（零基础）**

- 拍摄：手机竖屏即可。
- 录屏：系统自带或「录屏大师」。
- 剪辑：剪映（必用）。模板多、字幕自动、转场简单、可加进度条/数据标注。
- 封面：剪映内做，或 Canva。大字标题 + 关键数据（正确率、天数）+ 人脸或软件界面。
- 文案：提前写好 3 句核心（开头钩子 + 中间过程 + 结尾行动号召）。

**4. 创意与脚本模板（直接套用）**

- 开头 3 秒钩子：「今天资料分析正确率从 60% 提到 85%，我只用了软件里的这个功能……」
- 过程：屏幕录制 + 你的旁白（为什么这样选、错在哪里、软件怎么帮我复盘）。
- 结尾：展示足迹页/积分/连续天数 + 「关注我，一起用系统方法备考」+ 软件名称。
- 系列化：#30天公考打卡 #资料分析专项周 #申论开采日记 #模考复盘

**5. 发布与增长策略**

- 频率：初期每天 1 条，稳定后保持 5–7 条/周。
- 标签：公考、省考、行测、申论、资料分析、时政 + 热门相关。
- 互动：评论区置顶「软件使用方法」或「今日任务同步」，及时回复。
- 引流：视频结尾 + 主页简介放软件名/小程序码/链接（合规前提下）。
- 数据看：完播率 > 播放量，重点优化前 3 秒和字幕。
- 长期：把高质量视频二次剪成「方法合集」，做系列专栏。

**6. 常见坑与避坑**

- 不要一开始追求精致大片，真实过程最有说服力。
- 口播卡壳就重录，或后期配音。
- 每周固定一天做「复盘视频」，形成节奏感。
- 内容必须有「可行动」的点，观众看完知道明天可以怎么练。

### 总结与下一步建议

新应用完全聚焦公考，模块从现有「知行」中抽取并强化，加上真正可运营的社区，技术栈可无复用，开发路径清晰。产品做成「自己先用得爽、能坚持、能看见进步」的工具，视频号则是把这个过程公开化、内容化，形成「学习 → 记录 → 分享 → 获客 → 产品完善」的正循环。
